Sistema que permite a los usuarios registrados ver informacion sobre muchos personajes de la serie rick y morty a través de su api, sumado a eso el usuario puede agregar a favoritos el personaje de preferencia en una lista.

FUNCIONALIDAD
    El sistema permite al usuario registrarse e iniciar sesion
    El usuario navega entre pantallas para visualizar 
    El usuario puede filtrar la busqueda para los personajes
    El usuario puede agregar a una lista de favoritos
    Lista de favoritos persistente y privada

Para correr el proyecto
    Clonar el repo
    Ejecutar en terminal "flutter pub get"
    Ejecutar en terminal "flutter run"
